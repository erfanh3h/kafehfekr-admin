# کافه فکر — پنل و سرور اختصاصی مدیریت (Cafe Fekr Admin & Backend API)

مجموعه کامل و مستقل پنل مدیریت وب و سرور API اختصاصی برای پلتفرم آنلاین **کافه فکر (کافه بازی ۲۰ بازی آنلاین)**.

این مخزن کاملاً مستقل از سرور اصلی بازی (`kafehfekrserver`) بوده و روی پورت **۵۰۰۲** اجرا می‌شود تا هیچ بار اضافی بر سرور گیم وارد نکند.

---

## ۱. معماری و ساختار پروژه

```
kafehfekr-admin/
├── backend/                       # سرور اختصاصی FastAPI روی پورت ۵۰۰۲
│   ├── main.py                    # نقطه ورود سرور، تنظیم CORS، اتصال به مونگو و سرو فرانت‌اند
│   ├── requirements.txt           # پکیج‌های پایتون (FastAPI, PyMongo, Jose, Passlib)
│   ├── database/                  # مدیریت اتصال به KafehFekrDB و کالکشن admins
│   ├── security/                  # احراز هویت دیتابیسی ادمین‌ها، هش رمز (PBKDF2/Bcrypt) و توکن JWT
│   ├── services/                  # لاجیک کامل عملیات‌های مدیریتی (کاربران، بازی‌ها، صف، اقتصاد)
│   └── routers/                   # اندپوینت‌های REST API تحت /admin و /api/admin
├── frontend/                      # پنل وب React 19 + TypeScript + Vite + Lucide Icons
│   ├── src/                       # کامپوننت‌های داشبورد، مدیریت کاربران، راندهای بازی، کلن‌ها، گزارش‌ها
│   ├── package.json
│   └── vite.config.ts
├── Dockerfile                     # بیلد مولتی‌استیج داکر (Node جهت بیلد فرانت + Python جهت اجرای سرور)
├── docker-compose.yml             # راه‌اندازی با داکر کامپوز در شبکه kafehfekr_net
├── .env.example                   # متغیرهای محیطی نمونه
├── start_backend.bat              # اجرای سریع بک‌اند در ویندوز
├── start_frontend.bat             # اجرای سریع فرانت‌اند در محیط توسعه
└── build_all.bat                  # کامپایل بیلد نهایی فرانت‌اند
```

## ۲. قابلیت‌ها و عملیات‌های ادمین در پورت ۵۰۰۲

- **احراز هویت و ذخیره ادمین‌ها در دیتابیس مونگو:**
  - نام کاربری، نقش (`superadmin`, `admin`, `moderator`, `support`) و هش امن پسورد در کالکشن `admins` ذخیره می‌شود.
  - حساب پیش‌فرض اولیه: `admin` / `admin123456`.
- **داشبورد زنده و KPI:** آمار بازیکنان واقعی و بات‌ها، مسابقات فعال و خاتمه‌یافته، درآمد بسته‌ها، نمودار محبوبیت ۲۰ بازی در ۲۰۰ دست اخیر.
- **مدیریت کاربران:** جستجو، فیلتر بات/واقعی/بن‌شده، مشاهده پروفایل و تاریخچه برد/باخت، افزایش یا کسر سکه، امتیاز یا XP، آزادسازی قفل بازی (`open_game_id`)، بن/آن‌بن و اهدای سکه همگانی.
- **مدیریت مسابقات:** رصد مسابقات زنده، خاتمه اجباری مسابقه ناتمام و آزادسازی فوری هر دو بازیکن، آرشیو بازی‌ها و بازرس راندهای Bo3، پاکسازی خودکار بازی‌های معلق.
- **کنترل صف و سرور:** باز/بستن اضطراری صف ورود به مسابقات، زمان‌بندی خودکار، کنترل نسخه کلاینت گودوت (`allowed_version` و `latest_version`) برای اجبار به آپدیت، ارسال پیام بنر سراسری درون‌بازی.
- **فروشگاه و تراکنش‌ها:** گزارش پرداخت‌های کافه بازار و مایکت.
- **کلن‌ها و اتحادیه‌ها:** فهرست کلن‌ها، اعضا و انحلال کلن‌های متخلف.
- **گزارش‌ها و تخلفات:** صف شکایات و ریپورت‌ها با امکان حل، رد یا بن مستقیم کاربر متخلف.
- **پشتیبان‌گیری و لاگ:** اجرای فوری بک‌آپ مونگو (BSON Dump) و ثبت لاگ کلیه اقدامات مدیران در `admin_audit_logs`.

## ۳. نحوه اجرا در محیط محلی (Local Development)

### الف) اجرای سرور اختصاصی بک‌اند (Port 5002):
```powershell
cd D:\game\kafehfekr-admin\backend
pip install -r requirements.txt
python main.py
```
سرور در آدرس `http://localhost:5002` اجرا شده و مستقیماً به دیتابیس مونگو `KafehFekrDB` متصل می‌شود.
همچنین فرانت‌اند بیلدشده به صورت خودکار در آدرس **`http://localhost:5002/`** در دسترس است!

### ب) اجرای فرانت‌اند برای توسعه با قابلیت Hot-Reload (Port 3000):
```powershell
cd D:\game\kafehfekr-admin\frontend
npm install
npm run dev
```
فرانت‌اند در آدرس `http://localhost:3000` بالا می‌آید و به صورت پیش‌فرض درخواست‌ها را به `http://localhost:5002` ارسال می‌کند.

### ج) بیلد مجدد فرانت‌اند:
```powershell
cd D:\game\kafehfekr-admin\frontend
npm run build
```
فایل‌های خروجی در `frontend/dist` قرار گرفته و سرور پایتون ۵۰۰۲ بلافاصله آن را به کاربران نمایش می‌دهد.

## ۴. استقرار روی سرور لینوکس با داکر (Docker & Production Deployment)

این پروژه دارای `Dockerfile` مولتی‌استیج بهینه است که ابتدا فرانت‌اند را با Node کامپایل کرده و سپس در قالب یک ایمیج سبک پایتون با FastAPI سرو می‌کند (هر دو فرانت‌اند و بک‌اند روی تک‌پورت ۵۰۰۲ کار می‌کنند).

### روش ۱: اجرا از طریق داکر روت پروژه بازی (`d:\game\docker-compose.yml`)
سرویس `admin` به فایل اصلی `docker-compose.yml` در ریشه پروژه اضافه شده است:
```bash
./manage.sh start
# یا:
docker compose up -d --build
```
برای بررسی سلامت:
```bash
./manage.sh check
```

### روش ۲: اجرای مستقل با داکر در پوشه `kafehfekr-admin`:
```bash
cd kafehfekr-admin
docker compose up -d --build
```

### روش ۳: بیلد و اجرای دستی کانتینر داکر:
```bash
docker build -t kafehfekr-admin:latest .
docker run -d \
  --name kafehfekr_admin \
  -p 5002:5002 \
  --restart unless-stopped \
  --network kafehfekr_net \
  -e MONGO_URI="mongodb://mongo:27017/" \
  kafehfekr-admin:latest
```

پس از بالا آمدن کانتینر، پنل مدیریت در مرورگر سرور شما در آدرس زیر در دسترس خواهد بود:
👉 **`http://<SERVER_IP>:5002/`**
