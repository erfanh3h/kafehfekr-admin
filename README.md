# کافه فکر — پنل مدیریت رسمی (Cafe Fekr Admin Panel)

پنل مدیریت مدرن، جامع و سریع بازی آنلاین «کافه فکر» (مجموعه ۲۰ بازی تخته‌ای و کارتی آنلاین).

این پنل به مدیران و ناظران سرور اجازه می‌دهد تمامی عملیات مدیریتی، نظارتی، اقتصادی و فنی پلتفرم را با امنیت کامل، طراحی لوکس تیره (Dark Mode) و پشتیبانی دوزبانه (فارسی و انگلیسی) مدیریت کنند.

---

## ۱. ویژگی‌ها و عملیات‌های مدیریتی (Admin Actions)

### احراز هویت و امنیت ادمین‌ها در دیتابیس (Database Authorization & RBAC)
- **ذخیره ادمین‌ها در دیتابیس مونگو:** مشخصات ادمین‌ها به همراه هش امن رمز عبور (PBKDF2/Bcrypt) در کالکشن `admins` ذخیره می‌شود.
- **سطوح دسترسی و نقش‌ها (Role-Based Access Control):**
  - `superadmin`: دسترسی نامحدود به تمامی بخش‌ها و مدیریت سایر ادمین‌ها.
  - `admin`: مدیریت کاربران، بازی‌ها، صف، اقتصاد و تنظیمات سرور.
  - `moderator`: نظارت بر گزارش‌های تخلف، چت‌ها و اعمال بن/محدودیت.
  - `support`: مشاهده گزارش‌ها و پروفایل کاربران.
- **توکن‌های امن JWT:** احراز هویت با Bearer Token و انقضای خودکار نشست.
- **تغییر رمز عبور:** امکان تغییر رمز عبور مستقیم از طریق پنل مدیریت.
- **ادمین اولیه پیش‌فرض:** در صورتی که دیتابیس تازه باشد، ادمین `admin` با رمز `admin123456` به صورت خودکار ایجاد می‌شود (توصیه می‌شود در اولین ورود تغییر یابد).

### داشبورد و آمار تحلیلی (Dashboard & Analytics)
- کارت‌های شاخص کلیدی (KPI): تعداد کل بازیکنان، کاربران واقعی در برابر ربات‌ها، مسابقات برگزارشده، تراکنش‌های فروشگاه، گزارش‌های باز و کلن‌های فعال.
- نمودار توزیع و محبوبیت بازی‌ها در ۲۰۰ دست اخیر (ریسک، اونو، شطرنج، تیک‌تاک‌تو، منچ، یاتزی و...).
- **عملیات‌های سریع با یک کلیک:**
  - پاکسازی فوری بازی‌های گیرکرده و رهاشده
  - باز/بستن اضطراری صف مسابقات
  - اهدای سکه همگانی به بازیکنان
  - پشتیبان‌گیری فوری از پایگاه داده

### مدیریت کاربران (User Management)
- جستجوی پیشرفته با نام کاربری، شماره موبایل یا شناسه کاربر (`_id`).
- فیلتر بر اساس: همه کاربران، کاربران واقعی، حساب‌های بات (Bot)، کاربران مسدودشده.
- مرتب‌سازی بر اساس تاریخ ثبت‌نام، بیشترین امتیاز (Score)، بیشترین سکه، یا بیشترین تجربه (XP).
- **مشاهده پروفایل کامل:** تاریخچه برد/باخت/مساوی، مسابقات اخیر، خریدهای انجام‌شده و کلن کاربر.
- **تغییر دستی موجودی و ارزها:** افزایش یا کسر سکه (Coin)، امتیاز (Score) یا تجربه (XP) با ثبت دلیل در لاگ مدیریت.
- **مسدودسازی (بن / Ban):** مسدود کردن یا رفع مسدودیت حساب کاربری با یک کلیک.
- **آزادسازی قفل بازی (Reset Locks):** پاکسازی `open_game_id` و `open_pre_game_id` در صورت گیر کردن بازیکن در لابی یا بازی.
- **حذف کاربر:** حذف کامل حساب‌های تست یا متخلف.
- **اهدای سکه گروهی (Bulk Coins):** شارژ همگانی حساب کاربران واقعی یا فعال برای رویدادها و جوایز.

### مدیریت بازی‌ها و مسابقات (Games & Matches)
- **مسابقات زنده (Live):** مشاهده مسابقات در حال اجرای سرور Socket.IO، نوع مسابقه (رنک، کلاسیک، لابی)، بازیکنان حاضر و زمان شروع.
- **خاتمه اجباری مسابقه (Terminate Game):** قطع فوری بازی ناتمام و آزادسازی قفل هر دو بازیکن.
- **آرشیو تاریخچه مسابقات (History):** مرور بازی‌های پایان‌یافته با فیلتر بر اساس نوع بازی (Chess, Risk, etc.) یا حالت مسابقه.
- **بازرس راندهای مسابقه (Round Inspector):** مشاهده تمامی راندهای برگزارشده در سری‌های Bo3 به همراه برنده و زمان هر راند.
- **پاکسازی دسته‌جمعی بازی‌های معلق (Stuck Games Cleanup):** خاتمه دادن خودکار بازی‌هایی که بیش از زمان مجاز رها شده‌اند.

### تنظیمات سرور و صف مسابقات (Queue & Config)
- **کلید فعال/غیرفعال کردن صف مسابقات:** جلوگیری از ورود بازیکنان به صف در زمان نگهداری سرور.
- **زمان‌بندی خودکار صف:** تنظیم ساعت و دقیقه بازگشایی صف مسابقات.
- **مدیریت نسخه‌ها (Force Update Gate):** تنظیم `allowed_version` و `latest_version` برای اجبار کلاینت‌های گودوت به نصب آخرین نسخه.
- **اعلان درون‌بازی سراسری (Broadcast Banner):** ارسال و فعال‌سازی پیام اطلاع‌رسانی زنده برای همه بازیکنان در بازی.

### فروشگاه و پرداخت‌ها (Store & IAP Purchases)
- مشاهده گزارش تمامی پرداخت‌های درون‌برنامه‌ای کافه بازار و مایکت.
- فیلتر بر اساس مارکت (Cafe Bazaar / Myket) و نوع بسته سکه (بسته‌های ۵۰ تا ۱۷۰۰ سکه).
- جستجوی خریدهای یک کاربر خاص بر اساس شناسه.

### کلن‌ها و گروه‌ها (Clans Management)
- فهرست کلن‌های ثبت‌شده با نمایش تگ، سطح (Level)، جام‌ها (Trophies)، تعداد اعضا و رهبر کلن.
- بازرسی مشخصات کلن و فهرست اعضا با نمایش نقش‌ها (Leader, Co-leader, Elder, Member).
- انحلال و حذف کامل کلن‌های غیرفعال یا نامناسب.

### گزارش‌ها و نظارت بر تخلفات (Reports & Moderation)
- صف گزارش‌های ارسالی بازیکنان با دلیل تخلف، توضیحات و شناسه کاربر متخلف.
- فیلتر بر اساس وضعیت گزارش (معلق، بررسی‌شده، ردشده).
- اقدامات ناظر: ثبت نتیجه بررسی، رد گزارش، یا مسدودسازی (بن) فوری کاربر متخلف مستقیم از صفحه گزارش.

### مدیریت ادمین‌ها و پرسنل (Admins RBAC)
- مشاهده فهرست تمامی ادمین‌های ذخیره‌شده در دیتابیس.
- افزودن ادمین جدید با مشخص کردن نقش (`superadmin`, `admin`, `moderator`, `support`) و رمز عبور.
- فعال/غیرفعال‌سازی یا حذف حساب ادمین‌ها.

### پشتیبان‌گیری و لاگ رویدادها (Backups & Audit Trail)
- مشاهده فایل‌های پشتیبان BSON مونگو روی دیسک به همراه حجم و تاریخ.
- اجرای فوری پشتیبان‌گیری از دیتابیس با یک کلیک.
- ثبت و مرور تمامی اقدامات حساس مدیران در تاریخچه لاگ (`admin_audit_logs`).

## ۲. پشته فنی (Tech Stack)

- **Frontend:** React 19, TypeScript, Vite, Lucide Icons
- **Backend API:** FastAPI (Python 3.12), Python-JOSE (JWT), Passlib (PBKDF2/Bcrypt)
- **Database:** MongoDB 7.0 (`KafehFekrDB`)
- **Realtime Game Server:** Socket.IO ASGI (Port 5000)

## ۳. راه‌اندازی و اجرا (Quick Start)

### پیش‌نیازها
- Node.js (نسخه ۱۸ یا بالاتر) و npm
- Python 3.10+ با پکیج‌های نصب‌شده در `kafehfekrserver`
- MongoDB در حال اجرا روی `mongodb://localhost:27017/`

### اجرای فرانت‌اند در محیط توسعه (Development):
```bash
cd D:\game\kafehfekr-admin
npm install
npm run dev
```
پنل در آدرس `http://localhost:3000` در دسترس خواهد بود.

### ساخت بیلد نهایی (Production Build):
```bash
npm run build
```
فایل‌های کامپایل‌شده در پوشه `dist/` ایجاد می‌شوند.

### دسترسی مستقیم از طریق سرور اصلی (`kafehfekrserver`):
بیلد نهایی در پوشه `kafehfekrserver/static/admin` مستقر شده است. با اجرای سرور پایتون:
```bash
cd D:\game\kafehfekrserver
python main.py
```
پنل مدیریت بدون نیاز به نود مستقیماً در آدرس زیر در دسترس است:
👉 **`http://localhost:5001/admin-ui/`**
